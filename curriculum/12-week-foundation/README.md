# 12-Week Foundation Sprint

Start at [Week 1](week-01.md) and complete weeks in order. Each lesson contains an outcome, focused references, a hands-on exercise, evidence to commit and a completion gate.

The sprint builds one portfolio story: a read-only DevOps assistant that analyzes sanitized operational evidence, passes deterministic checks and produces only simulated actions with an audit trail.

Use [the weekly progress template](../../weekly-progress/TEMPLATE.md) after each lesson.
